# Crypto Profit/Loss Pro

A modern, responsive Crypto Profit/Loss Calculator built with **Node.js**, **Express**, **Tailwind CSS**, and **Lucide Icons**. It features real-time price integration via the **CoinGecko API**.

## 🌟 Features

- **Dual Calculation Modes:** Traditional (Quantity-based) and Investment (Total spend-based).
- **Live Price Integration:** Fetch real-time market values for top cryptocurrencies.
- **Multi-Currency Support:** Calculate in USD, INR, EUR, GBP, or JPY.
- **Optional Trading Fees:** Include buy and sell fees for precise net profit tracking.
- **Glassmorphic UI:** Clean, dark-mode centric design with dynamic visual indicators.
- **Responsive:** Fully optimized for mobile and desktop.

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   ```
2. **Navigate to the directory:**
   ```bash
   cd crypto-calc-web
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the server:**
   ```bash
   npm start
   ```
5. **Open your browser:** Go to `http://localhost:3000`

## 📂 Project Structure

- `server.js`: Node.js Express server.
- `public/index.html`: Main application UI and logic.
- `crypto-calculator.html`: Standalone single-file version.
